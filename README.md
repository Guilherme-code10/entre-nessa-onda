# Entre Nessa Onda 🌊

Sistema web para organização de voluntários e ações sociais do projeto Entre Nessa Onda.

## Sobre o projeto

O Entre Nessa Onda é uma iniciativa social voltada ao atendimento de crianças da comunidade.

Este projeto de software tem como objetivo melhorar o planejamento das ações, a organização das equipes e o acompanhamento dos voluntários.

## Funcionalidades previstas

- Cadastro de voluntários e setores
- Calendário de eventos
- Organização de escalas
- Confirmação de disponibilidade
- Registro de presença
- Controle de acesso por perfil

## Tecnologias planejadas

- Angular e TypeScript
- Node.js e Express
- PostgreSQL
- Git e GitHub

## Estrutura atual

A pasta do protótipo contém:
- Interface demonstrativa em HTML
- Três capturas de tela
- Instruções de utilização

## Status

Projeto acadêmico em desenvolvimento.

O protótipo demonstra o fluxo de consulta e confirmação de escalas. A implementação completa do MVP será realizada nas próximas etapas.

## Objetivo social

Contribuir para uma gestão mais eficiente e organizada das ações comunitárias, alinhada ao ODS 16, meta 16.6.
